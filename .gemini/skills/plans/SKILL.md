# Skill: Plans

- Sempre siga o fluxo para nos planos que forem adicionados em @.gemini/plans

## Fluxo

1. O plano deve sempre criar uma branch nova a partir da branch `main.py`
2. Toda task feita pelo plano deve ter um commit
3. Ao finalizar o plano deve abrir um pull request listando as alterações
